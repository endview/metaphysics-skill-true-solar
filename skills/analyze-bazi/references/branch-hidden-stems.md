# 十二支藏干

采用下列常见藏干序列。顺序表示从主要到次要的约定顺序，不把它当作统一的数值权重；不同流派对余气、月令分日和权重可能另有定义。

| 地支 | 藏干（依序） |
|---|---|
| 子 | 癸 |
| 丑 | 己、癸、辛 |
| 寅 | 甲、丙、戊 |
| 卯 | 乙 |
| 辰 | 戊、乙、癸 |
| 巳 | 丙、戊、庚 |
| 午 | 丁、己 |
| 未 | 己、丁、乙 |
| 申 | 庚、壬、戊 |
| 酉 | 辛 |
| 戌 | 戊、辛、丁 |
| 亥 | 壬、甲 |

对每个藏干按日主重新计算十神。不要把地支整体直接等同于一个十神，也不要仅凭藏干出现就断定其透出、得令、成格或发挥吉凶作用。
