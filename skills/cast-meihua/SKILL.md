# 梅花：固定问题，计算一次

只处理用户明确选择的梅花单方法，组合交给 `$metaphysics`。把卦象作为有限象征解释，不作为隐藏事实探测或概率模型。

先读[可靠执行协议](references/runtime-protocol.md)与[起卦协议](references/protocol.md)。正式新请求使用 `scripts/run-verified.mjs`，不要直接运行原生 CLI 绕过冻结和执行记录。

## 冻结

需要具体对象、独立事件、命题、问题、观察窗口、判断标准、应期 profile/单位、时间来源及方法。已经提供完整信息就执行，不机械再问“开始”。二选一、成功定义、预算阈值必须由用户给定，不能看卦后发明。

`method_inputs` 包括 `native_method:lunar-time-v2|numbers-v2`、`time_basis:civil|true_solar`、`timing_profile:{profile,unit}`。数字法另传恰好两个或三个正安全整数 `numbers` 和 `number_grouping_confirmed:true`；单个三位数不拆位。`time_request` 记录宿主或用户的民用时间来源与 IANA 时区；真太阳时还需协议指定的无偏移连续太阳钟面、原始民用时、地点/经度及可核查换算来源。

`now` 由宿主在冻结前读取一次，原生计算器只收到固定时点；复用和技术重试不再取当前时间。用户选择历史时点时保持历史时点。没有真实外部换算器则太阳时未解析，不编写近似公式冒充工具。

无需出生日期、性别、姓名。数字法民用时不索取无关出生地点。来源精度保留，日期 carrier 不是起卦 instant。

## 计算与解释

原 `numbers-v2`、`lunar-time-v2` 算法及 `cast-meihua/result-v2` 不变。计算器返回本变互错综、动爻、体用与余数，固定事实块不得手工改写。错误停止，技术重试限相同冻结输入。

解读前读[解释规则](references/interpretation.md)及[输出契约](references/output-contract.md)，按问题→本卦→体用→动爻→变卦→互卦→错综顺序。使用匹配的本卦主题与经卦卡，最多两个与具体问题直接相关的读法，并写出反证。后面的派生卦不得推翻前面的不利信息来迎合结果。

`calculation_review` 只核事实，`symbolic_event` 需模型草稿加知识卡后 finalize。`stage-within-horizon-v1` 只输出由动爻对应的阶段；`moving-line-count-v1` 固定单位、锚点、最大数量和窗口，超界不扩大期限。观察期的具体日期不授权编造精确应期。

同一对象同一事件不因改词、改期限、换数字、换算法、不满意或“再确认”重起。新周期需期满并保留复盘；输入错误需有更正依据并保留失效记录。现实反馈单独存储，不能说旧卦早已预测新消息。

交付主要象征倾向、计算依据、不能判断的部分和有现实根据的行动。不得断言他人动机、定位失物、诊断设备或疾病、保证结果或提供准确率。
