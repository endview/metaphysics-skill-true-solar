# 能力登记与宿主边界

读取 capability-manifest.v1.json。当前候选提供 method-v5；knowledge、utility、workflow 顶层 provider 保持 reserved，不自动启用。包内知识卡和内部时间校验不等于启用这些顶层服务。

加载、进程执行、Chinese calendar、模型分支隔离、工具观察、存储六项分别查询。能读 Skill 不证明独立分支，VM 不证明语言模型隔离。默认本地主机只有本地受控 runner 观察与会话状态；模型隔离 unavailable，外部太阳时转换器 unavailable。

只有宿主登记的实际安装路径可分派。找不到子包返回 unavailable；未知方法 unsupported。禁止凭模型记忆模拟缺少的工具或星盘。

生产激活与可调用候选代码分开：本候选入口可运行 method-v5，但没有自动安装、远端默认切换、跨环境或模型矩阵认证。发布检查如实展示缺失项。
