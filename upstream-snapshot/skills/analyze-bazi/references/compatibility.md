# 合盘协议

## 前置条件

分别建立两人的出生资料等级和命盘等级。确认用户有权使用对方资料，并去掉姓名、详细地址、证件或无关身份信息。任何一盘不确定时，先保留候选盘。

## 分析顺序

1. 先独立分析 A 盘，不参考 B 盘来修正 A 的叙事。
2. 再独立分析 B 盘，不参考 A 盘来修正 B 的叙事。
3. 冻结两份独立结论后，才检查两盘之间的干支关系与所选流派解释。
4. 区分结构事实、传统解释和现实关系证据。
5. 总体置信度取两盘置信度的较低者；若出生边界会改变互动结论，再下调。

不得只凭合、冲、某一十神或日柱给“合/不合”分数，也不得断言婚期、离婚、出轨、性行为、生育、伤害或谁“克”谁。把沟通、价值观、边界、冲突修复、生活目标和安全等现实信息放在决策前面。

## 妻星与夫星

妻星/夫星是某些传统体系中的角色化视角，不是人的性别、性取向、伴侣身份或关系质量事实。先问用户是否要采用该传统视角，以及希望使用哪一角色标签；不得从姓名、外表或既有伴侣关系猜测。

用户不选择时，使用中性技术名称（如财星、官杀）或完全省略角色化映射。即使用户选择，也要标明这是传统象义之一，不把“有/无/强/弱”直接解释为配偶存在、价值、忠诚或婚姻结果。

## 输出

依次给出：A 的独立摘要与置信度、B 的独立摘要与置信度、互动事实、所选流派解释、现实核对问题、共同/分歧项、总体置信度与限制。最终建议必须回到双方的现实行为和沟通继续判断。
