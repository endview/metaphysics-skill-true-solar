# 运行与模型支持矩阵

本地已执行环境：Node 22.16.0、ICU 77.1、Linux。确切版本以生成的 test-report.json 为准。四个目录的独立复制和 ZIP 解压运行由 smoke 工具实际检查，不依赖网络下载。

| 环境/能力 | 状态 | 边界 |
|---|---|---|
| 当前 Linux / Node 22.16.0 | 已测试 | 见当前源码绑定报告 |
| 原生三方法计算及双阶段封装 | 已测试 | 合成输入，不评价预测效度 |
| 四包独立目录 / ZIP | 由实际构建冒烟报告给出 | 不是 ChatGPT UI 安装 |
| 当前会话 / 包外授权状态 | 已实现并测试 | 默认不持久化；会话丢失不保证永久去重 |
| 多方法本地分派 | 已实现 | 缺独立模型上下文时 partial / blocked_isolation |
| Windows / macOS / Linux / Node 22.16.0 | 发布流水线验证 | 以对应提交的三个 Actions 作业及报告为准，不代表产品认证 |
| 其他 Node 版本 | 非锁定复现环境 | 不作为发布验收依据 |
| ChatGPT / Codex / Atlas 产品安装 | 未验证 | 包格式检查不等于产品安装 |
| 真实语言模型行为矩阵 | 未运行 | 需要宿主适配器、独立评审和运行轨迹 |
| 外部太阳时转换 provider | 未配置 | 有接口，无近似算法或虚假核验 |

模型测试报告必须写入实际模型 ID、宿主、参数、时间、工具轨迹、独立评审来源及全部失败。没有这些记录时，完整生产验收 gate 保持阻断，GitHub 工程版本发布不改变这一结论。仅能读取文本的宿主不能把导入记录提升为 host_observed。

持续集成配置是可运行配置，是否实际执行以 GitHub Actions 记录为准，不把 YAML 文件当测试证据。模型评测作业不在携带密钥的不可信 PR 上运行。
