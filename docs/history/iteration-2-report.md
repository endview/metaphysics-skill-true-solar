## 2. 可以做什么，以及不能做什么

八字可以审阅给定四柱及可选大运/流年的字符、干支配对、十神、藏干和固定关系。给定来源P0与实际结构检查P1分列；用户声明的真太阳时仍是 `user_declared`，没有P2历法核盘。

梅花保留 `numbers-v2` 与 `lunar-time-v2`，可以按冻结个案运行原生算法并交付计算事实。受控入口会检查数字分组、完整窗口、IANA时区与偏移、时间来源及太阳钟面条件。`now`由会话宿主读取一次，重试和重复启动不再取新时刻。原生“specified”不会覆盖原来的宿主时钟来源。

**两个候选入口都只接受用户明确要求的计算事实审阅。** 旺衰、用神、自由象征解释、事件成败预测、合盘解释、紫微和多方法综合均不在当前完成范围内。不能把这些完整问题悄悄改成结构问题再标成功。缺少已验收的解释能力时直接说明缺口，不用免责声明配上未经检查的预测。

持续会话通过NDJSON保存状态；一次性模式仅用于明确的新审阅事件。去重范围是当前进程，不是跨对话永久保证。下载的审计JSON也不是可恢复的会话数据库。
