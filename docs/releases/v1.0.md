# v1.0

面向八字、紫微斗数与梅花易数咨询的四个独立 Skill，提供输入核对、原生计算、分析流程和统一结果规范。

## 功能

- **metaphysics 主路由**：根据问题选择适用方法，组织子方法结果并检查各方法的适用范围。
- **analyze-bazi 八字**：检查已提供四柱的结构、十神、藏干与干支关系，配套原局及岁运分析参考。
- **analyze-ziwei 紫微斗数**：使用 iztro 2.5.8 排盘，支持真太阳时输入约束、候选配置比较及本命、大限、流年事实整理。
- **cast-meihua 梅花易数**：支持农历时间法 `lunar-time-v2` 和数字法 `numbers-v2`，规范问题、数字分组、时间口径与解释流程。

## 使用与下载

八字结构检查以用户提供的四柱为输入。紫微按输入契约接收已校准的真太阳时资料；梅花按所选协议使用民用时或真太阳时。

下载 `metaphysics-skills-v1.0.zip`，解压后分别导入各子目录中的 `skill.zip`。`metaphysics-source-v1.0.zip` 提供完整源码，`SHA256SUMS-v1.0.txt` 提供附件校验值。
