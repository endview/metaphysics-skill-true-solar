# v1.1

在四个独立 Skill 的基础上，改进执行一致性、同一问题的结果复用、时间资料管理和解释结果校验。

## 更新日志

- **统一执行流程**：八字、紫微和梅花使用“原生计算 → 模型解释草稿 → 校验 → 标准结果”流程，固定运行入口，加入源码摘要、输入输出大小和进程超时检查。紫微先预检输入，再加载引擎。
- **个案与事件管理**：绑定对象、事件和命题；冻结同一事件的问题、时间范围及首次结果；补充资料时复用已完成分支，区分技术重试、资料纠错和新周期。
- **主路由升级**：新增 `method-v5` 两阶段编排，支持缺失输入补全、解释续接、覆盖检查及防递归。多方法综合检查独立上下文条件，条件不足时明确报告。
- **时间与候选资料**：统一时区、夏令时歧义、冻结的当前时间、真太阳时来源及精度；支持明确关联的候选集合。外部转换接口在缺少已审查来源时返回未解析。
- **解释与来源约束**：加入 102 张简短来源卡，提供适用条件、反证及不可推断项；校验事实引用并记录解释版本，区分计算事实、传统解释和现实建议。
- **可选保存**：默认使用会话内状态；获得明确授权后可保存到包外，带原子写入和并发约束，现实观察单独记录。
- **构建与验证**：加入 11 份 JSON Schema、来源锁、四包允许清单、独立 ZIP 解压运行检查及 Linux、Windows、macOS 工程验证流水线。

## 兼容性

八字与梅花原生计算器以及 iztro 2.5.8 第三方内容保持原样。旧原生协议和标准子结果保留；新增编排使用明确的 `method-v5` 版本。主路由通过宿主登记各子包的实际安装路径，不要求固定的兄弟目录布局。

## 验证范围

发布前须通过三个操作系统上的工程验证；具体测试数量、环境版本、源码指纹和各项结果见本版本源码包的 `reports/` 及 GitHub Actions。测试使用合成资料。

真实模型／宿主行为矩阵尚未运行，完整生产验收仍为未通过；跨平台工程测试不等于 ChatGPT 产品安装认证。外部真太阳时转换 provider 尚未配置，历史 468 项审计未逐项复现。现有自然语言校验和知识卡也不代表现实预测准确性认证。
