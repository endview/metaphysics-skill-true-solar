# 十二宫领域地图

宫位是传统分类入口，不是现实人物或事件的事实标签。每个结论都要结合目标宫、三方四正、命/身背景、运限与四化，并检查反证。

| 宫位 | 现代中性领域 | 本方法解释范围 | 非本方法输出 |
|---|---|---|---|
| 命宫 | 自我角色与惯常应对 | 自我表达、决策偏好、角色重心 | 固定人格诊断、道德品质、宿命标签 |
| 兄弟宫 | 同辈与横向协作 | 同辈沟通、资源协调、支持边界 | 兄弟姐妹数量、寿命、疾病或祸福 |
| 夫妻宫 | 亲密关系中的自身模式 | 期待、表达、承诺、边界、冲突修复 | 伴侣品德、出轨、性行为、必婚或必离 |
| 子女宫 | 照护、创造与传承 | 照护方式、作品/项目投入、与晚辈互动 | 生育能力、子女数量/性别、孕产结果、子女命运 |
| 财帛宫 | 金钱行为与资源配置 | 收支关注、预算、现金流习惯、资源交换 | 投资收益、价格走势、借贷批准、赌博结果 |
| 疾厄宫 | 身心负荷与照护行为 | 作息、压力观察、就医准备、自我照护 | 疾病、器官、诊断、治疗、寿命、意外 |
| 迁移宫 | 外部环境与移动适应 | 异地适应、变化承受、外部机会的现实条件 | 唯一吉方、指定城市、出行成败或事故 |
| 交友宫 | 网络、协作与授权 | 团队互动、合作边界、授权与求助方式 | 内鬼、背叛、犯罪、他人隐蔽动机 |
| 官禄宫 | 工作角色与长期投入 | 职责偏好、组织环境、能力使用、发展议题 | 录用、晋升、解雇、考试、收入的确定结果 |
| 田宅宫 | 居住环境与家庭资源 | 居住需求、家庭协商、资产文件与维护清单 | 房价、交易时机、产权结论、结构或电气安全 |
| 福德宫 | 主观满足与恢复方式 | 休息、注意力、意义感、恢复习惯 | 抑郁、焦虑、人格障碍、自杀风险等临床判断 |
| 父母宫 | 原生家庭与权威互动 | 支持渠道、代际沟通、制度/权威关系 | 父母寿命、疾病、品德、因果或“克亲” |

“仆役宫”等旧称统一映射为交友/协作领域。古籍中的身份等级、性别规范、身体污名、贞洁判断和灾祸标签不直接进入现代输出。

## 领域组合

### 事业

以官禄宫为目标，结合其三方四正，并读取命宫/身宫、迁移宫和财帛宫中与工作角色及资源方式直接相关的结构。财帛内容使用 `finance-habits` 配置。

### 关系中的用户自身模式

以夫妻宫为目标，结合其三方四正，并读取命宫/身宫、福德宫及交友宫中与表达、边界和支持网络相关的结构。只讨论用户可观察和可调整的部分。

### 迁移与环境

以迁移宫为目标，结合其三方四正，并读取命宫/身宫、官禄宫和交友宫中与适应、工作环境和外部协作相关的结构。地点选择必须回到成本、资格、支持网络与客观机会。

### 阶段主轴

先看大限和流年落入哪些宫位及四化如何连接本命结构，再选出证据最集中的两至三个领域。不得把十二宫逐宫写成事件清单。

## 结论门槛

领域结论至少包含：

1. 目标宫事实；
2. 三方四正中的支持结构；
3. 运限/四化如何改变关注点；
4. 至少一项相反或缓和证据；
5. 候选盘是否稳定；
6. 与现实基线相符或冲突之处。

任一关键环节缺失时，降低结论强度或明确不可判断。
