# 十干与十神

在计算任何十神前读取本表。十神永远以**当前日主**为参照，不得把辛金或任何单一日主的对应关系推广为通用五行规则。

## 十干属性

| 天干 | 五行 | 阴阳 |
|---|---|---|
| 甲 | 木 | 阳 |
| 乙 | 木 | 阴 |
| 丙 | 火 | 阳 |
| 丁 | 火 | 阴 |
| 戊 | 土 | 阳 |
| 己 | 土 | 阴 |
| 庚 | 金 | 阳 |
| 辛 | 金 | 阴 |
| 壬 | 水 | 阳 |
| 癸 | 水 | 阴 |

生序：木生火、火生土、土生金、金生水、水生木。

克序：木克土、土克水、水克火、火克金、金克木。

## 由日主推十神

先判断目标干与日主的五行关系，再判断阴阳同异：

| 目标干相对日主 | 同阴阳 | 异阴阳 |
|---|---|---|
| 同我 | 比肩 | 劫财 |
| 生我 | 偏印 | 正印 |
| 我生 | 食神 | 伤官 |
| 我克 | 偏财 | 正财 |
| 克我 | 七杀 | 正官 |

“同阴阳”指两干同为阳或同为阴，不是同字；具体映射以关系规则及十日主速查表为准。
